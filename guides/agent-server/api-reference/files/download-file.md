# Download File

Download a file from the server

## Endpoint

```
GET /api/files/{file_id}
```

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `file_id` | string | Yes | The file ID |

## Response

**200** - Successful Response
