# Download Trajectory

Download the conversation trajectory

## Endpoint

```
GET /api/conversations/{conversation_id}/trajectory
```

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `conversation_id` | string<uuid> | Yes | The conversation ID |

## Response

**200** - Successful Response
