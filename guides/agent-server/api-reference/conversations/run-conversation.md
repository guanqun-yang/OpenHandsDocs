# Run Conversation

Run or resume a conversation

## Endpoint

```
POST /api/conversations/{conversation_id}/run
```

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `conversation_id` | string<uuid> | Yes | The conversation ID |

## Response

**200** - Successful Response
