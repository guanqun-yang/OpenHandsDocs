# Set Conversation Security Analyzer

Set the security analyzer for a conversation

## Endpoint

```
POST /api/conversations/{conversation_id}/security_analyzer
```

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `conversation_id` | string<uuid> | Yes | The conversation ID |

## Response

**200** - Successful Response
