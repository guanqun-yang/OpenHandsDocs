# Delete Conversation

Delete a conversation by ID

## Endpoint

```
DELETE /api/conversations/{conversation_id}
```

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `conversation_id` | string<uuid> | Yes | The conversation ID |

## Response

**200** - Successful Response
