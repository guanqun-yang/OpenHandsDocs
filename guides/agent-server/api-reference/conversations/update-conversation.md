# Update Conversation

Update conversation details

## Endpoint

```
PATCH /api/conversations/{conversation_id}
```

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `conversation_id` | string<uuid> | Yes | The conversation ID |

## Response

**200** - Successful Response
