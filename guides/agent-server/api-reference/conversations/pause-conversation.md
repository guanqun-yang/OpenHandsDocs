# Pause Conversation

Pause a running conversation

## Endpoint

```
POST /api/conversations/{conversation_id}/pause
```

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `conversation_id` | string<uuid> | Yes | The conversation ID |

## Response

**200** - Successful Response
